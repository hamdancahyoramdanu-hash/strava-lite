Cara Upload ke GitHub Pages

Penting: API GPS Browser (Geolocation) wajib menggunakan protokol HTTPS. GitHub Pages otomatis menyediakan HTTPS gratis sehingga pelacakan GPS di HP berjalan lancar!
  1. Simpan kode aplikasi ini dengan nama file index.html.
  2. Buka github.com dan buat repository baru (misal: strava-lite) dengan visibilitas Public.
  3. Klik Add file → Upload files, lalu unggah file index.html Anda dan klik Commit changes.
  4. Masuk ke tab Settings → Pages di repository tersebut.
  5. Pada bagian Build and deployment → Branch, pilih main dan folder / (root), lalu klik Save.
  6. Tunggu sekitar 1 menit, tautan aplikasi Anda (https://username.github.io/strava-lite/) siap dibuka di smartphone Anda!
